# ALIMENTA+ | Mapa do ecossistema

Este documento registra como as ferramentas do projeto se relacionam.

## Fontes de verdade

| Área | Fonte principal |
|---|---|
| Requisitos, decisões e histórico | Notion |
| Tarefas e execução | Trello |
| Interface e experiência | Figma |
| Código e versionamento | GitHub |
| Comunicação, apresentação e criatividade | monday.com |
| Validação | QA |

## Regra de sincronização

Uma mudança relevante deve ser rastreada da decisão até a validação. A equipe deve identificar a tarefa no Trello, verificar impacto no Figma, registrar decisões permanentes no Notion, implementar e versionar no GitHub e validar com QA.

## Estado das telas

Projetada no Figma → Em implementação → Implementada → Validada por QA.

## Histórico

Checkpoints históricos não devem ser sobrescritos para aparentar um estado atual. O registro deve permitir reconstruir o que existia, o que mudou, por que mudou, o que foi validado e qual é o estado atual.

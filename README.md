# ALIMENTA+

Plataforma ALIMENTA+ para conectar excedentes de alimentos a novos destinos, transformando desperdício em valor.

## Sobre o projeto

O ALIMENTA+ é um projeto em evolução que integra produto, experiência do usuário, desenvolvimento web, impacto social, acessibilidade e apresentação profissional.

## Ecossistema de gestão

- **GitHub:** implementação, versionamento e documentação técnica ligada ao código.
- **Notion:** requisitos, decisões, arquitetura, histórico e documentação consolidada.
- **Trello:** tarefas, prioridades, dependências e acompanhamento operacional.
- **Figma:** interfaces, fluxos, componentes e identidade visual.
- **monday.com:** campanhas, comunicação, apresentação e projetos criativos.
- **QA:** validação dos fluxos, critérios de aceite e qualidade do produto.

## Estrutura prevista da implementação


A estrutura existente do projeto deve ser preservada durante a migração para o repositório. Arquivos legados não devem ser removidos ou renomeados sem validação da arquitetura e dos fluxos que dependem deles.

## Estado de gestão em 22/09/2026

O projeto está em fase de consolidação e sincronização entre design, implementação, documentação, execução e QA.

A gestão utiliza quatro estados para cada tela ou fluxo:

1. Projetada no Figma
2. Em implementação
3. Implementada
4. Validada por QA

A existência de uma tela no Figma não é, por si só, evidência de implementação ou validação.

## Princípios

- Preservar histórico e checkpoints anteriores.
- Evitar duplicação desnecessária entre ferramentas.
- Registrar decisões permanentes no Notion.
- Executar tarefas e acompanhar andamento no Trello.
- Usar o Figma como referência visual.
- Manter o GitHub como fonte do código versionado.
- Validar mudanças relevantes com QA antes de considerá-las concluídas.

## Arquitetura em acompanhamento

A camada compartilhada atualmente identificada no workspace é `cammom.js`. Registros antigos podem mencionar `common.js`; essa diferença deve ser tratada como histórico até que a arquitetura seja validada novamente.
